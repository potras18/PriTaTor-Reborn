PriTaTor Reborn is a Priston Tale server manager and map editor. One exe, nothing to install.

PriTaTor has been a favourite in the PT scene since 2008, but its map editor needed each map lined up by hand before it worked. PriTaTor Reborn is a new tool, written from scratch, that keeps the idea, removes the setup and draws your maps with their real textures.

Put the exe in your server folder and run it. It reads your own map files, works out where every map sits and writes its own settings file. A loading window shows what it's doing. It only prepares each map once, so later starts are quick, and if a map file changes it updates just that map by itself.

Textured maps

  • Draws every map from straight above with its real textures, lighting and transparency, at 2048 pixels
  • Flags and NPCs line up exactly, because the picture comes from the map's own geometry
  • To turn it on, copy the client's textures into your server's Field folder, or use File > Use textures from a client folder. Servers don't normally hold textures, as they don't need them
  • On a hard drive it takes roughly 20 seconds, once. After that a map is only redrawn if its file changes
  • With no textures you get plain terrain, so maps with no minimap still work
  • The pictures are saved as JPGs in PriTaTor\Terrain, for you to use however you like

Map editor

  • See every monster flag and NPC on the map, lined up automatically
  • Drag to move, click to add, Del to remove, with full undo
  • Turn NPCs with a handle or by typing a bearing, so they face the right way
  • NPCs land on the ground at the height of the terrain, even under a tree
  • Edit each map's monster list, spawn rates and bosses

Moved maps

  • Picks up every map in your Field folder, including moved and older copies like old\forest\o_fore-1
  • Finds how far a copy has moved, even when it's an older version of the map
  • Imports flags, NPCs and monsters onto a moved map in one step
  • Warns when a map's flags and NPCs are off the map, and can shift them all back

Data files

  • Monsters, NPCs, items and name files as labelled English fields, or as raw text
  • A text editor for any settings file in the server folder
  • See which maps a monster spawns on
  • NPC shop editor: pick what an NPC sells by category and name, with no item codes to type
  • Names come from your .zhoon files, whichever language letter they use (E_NAME, J_NAME, B_NAME and so on)
  • Korean text is safe: saving only changes the lines you edited
  • Every save keeps a backup of the old file

Needs Windows 10 or 11. Reload your server after saving, since it only reads these files at start-up. In-game testing is still under way, so please back up your server first and let me know what you find.
